# Buckets v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the buckets screen into a trustworthy, interactive editor: a draggable allocation bar (dividers set percentages, two-way linked to the list), per-bucket ⋯ menu (Rename / Recolor / Delete), drag-to-reorder, a bucket cap (Free 5 / Premium 15) with an upgrade upsell, and delete-redistributes-to-Savings so totals always stay valid.

**Architecture:** All the risky math lives in a **pure module** (`lib/buckets/edit.ts`): re-splitting two adjacent buckets when a divider moves, deleting a bucket by folding its % + balance into Savings, and cap checks — each a pure function over the bucket array, unit-tested, integer-percent-safe, total always 100. The UI is composed from focused components: `AllocationBar` (draggable dividers), `BucketRow` (dot, name, %, ⋯ menu, drag grip), `BucketMenu` (Rename/Recolor/Delete popover), and a rebuilt `BucketSetup` that wires them to the pure logic and persists via the existing `saveBuckets`. The cap reads a premium flag through a seam (defaults to Free until billing lands). Delete's balance move reuses the existing money-conserving transaction pattern.

**Tech Stack:** Next.js 16 client, React 19, `@dnd-kit/core` + `@dnd-kit/sortable` (reorder — a focused, well-maintained lib; hand-rolling drag-reorder is error-prone), Firestore, Vitest + RTL.

## Global Constraints

- **Percentages are integers summing to exactly 100.** Every edit (drag, delete, add) must leave the set summing to 100 or clearly mark it invalid (Save disabled). No fractional-percent drift.
- **Two-way link:** the allocation bar and the list show the SAME state. Dragging a divider updates the two adjacent buckets' percents; the list reflects it live, and vice-versa. One source of truth (the bucket array in state).
- **Delete = redistribute to Savings** (validated decision): the deleted bucket's percent is added to the Savings bucket (fallback: the first remaining bucket if no bucket named/typed "savings"), and its remaining balance is moved to that bucket so no money is lost and total stays 100.
- **Bucket cap:** Free = 5, Premium = 15. Adding beyond the cap is blocked and shows the "Need more buckets?" upsell. The cap reads premium via a seam (`usePremium` when billing exists; until then default Free=5). Never let the client grant itself premium.
- **Money integer cents**; the delete balance move is idempotent + conserving (reuse the transaction pattern from `applyRebalance`/`applySpend`).
- **Reuse:** `Bucket` type + path helpers; `BUCKET_DOT_COLORS`/`pickDotColor` from `@/lib/theme` (the recolor palette); `saveBuckets` from `@/lib/data/buckets`; design tokens + T1 primitives; the pure `SplitRule` shape stays compatible with `SplitEngine`.
- **No emojis, dark tokens, no `any`.** Accessibility: the ⋯ menu is keyboard-openable; drag handles have accessible labels; the bar dividers are also adjustable without a mouse (number-input fallback in the row).
- **Preserve `data-testid="total-percent"`** and the `onSave(buckets)` contract so existing tests/consumers keep working.

## Task 1: Pure edit logic (re-split, delete, cap)

**Files:**
- Create: `lib/buckets/edit.ts`
- Test: `lib/buckets/edit.test.ts`

**Interfaces:**
- Consumes: `Bucket`, `Cents`.
- Produces:
  - `bucketCapFor(premium: boolean): number` → `premium ? 15 : 5`.
  - `canAddBucket(buckets: Bucket[], premium: boolean): boolean` → `buckets.length < bucketCapFor(premium)`.
  - `resplitAdjacent(buckets: Bucket[], leftIndex: number, newLeftPercent: number): Bucket[]` — a divider sits between `leftIndex` and `leftIndex+1`; moving it sets the left bucket to `newLeftPercent` (clamped to `[0, left+right]`) and gives the remainder to the right bucket, so `left+right` is unchanged and the overall total stays 100. Returns a new array (integers).
  - `deleteBucket(buckets: Bucket[], bucketId: string): Bucket[]` — removes the bucket; adds its `percent` to the Savings bucket (first bucket whose name lowercases to "savings", else the first remaining bucket) and its `remaining`+`allocated` too (so balances aren't lost); total stays 100. Throws if deleting the last remaining bucket.

- [ ] **Step 1: Write the failing tests**

`lib/buckets/edit.test.ts`:
```ts
import { describe, it, expect } from "vitest";
import { bucketCapFor, canAddBucket, resplitAdjacent, deleteBucket } from "@/lib/buckets/edit";
import type { Bucket } from "@/lib/model/types";

const mk = (id: string, name: string, percent: number, remaining = 0): Bucket =>
  ({ id, name, colorIndex: 0, percent, type: "virtual", remaining, allocated: remaining });

const set: Bucket[] = [mk("rent", "Rent", 35), mk("sav", "Savings", 30, 50000), mk("food", "Food", 15, 18000), mk("fun", "Nights out", 10), mk("gym", "Gym", 10)];

describe("cap", () => {
  it("free=5, premium=15", () => { expect(bucketCapFor(false)).toBe(5); expect(bucketCapFor(true)).toBe(15); });
  it("blocks add at the free cap", () => { expect(canAddBucket(set, false)).toBe(false); expect(canAddBucket(set.slice(0,4), false)).toBe(true); });
  it("premium allows more", () => { expect(canAddBucket(set, true)).toBe(true); });
});

describe("resplitAdjacent", () => {
  it("moving the Rent|Savings divider re-splits only those two, total stays 100", () => {
    const out = resplitAdjacent(set, 0, 40); // Rent 35->40, Savings 30->25
    expect(out[0].percent).toBe(40);
    expect(out[1].percent).toBe(25);
    expect(out.reduce((t, b) => t + b.percent, 0)).toBe(100);
  });
  it("clamps so neither adjacent bucket goes negative", () => {
    const out = resplitAdjacent(set, 0, 999); // can't exceed left+right (65)
    expect(out[0].percent).toBe(65);
    expect(out[1].percent).toBe(0);
    expect(out.reduce((t, b) => t + b.percent, 0)).toBe(100);
  });
});

describe("deleteBucket", () => {
  it("folds percent + balance into Savings, total stays 100, money conserved", () => {
    const out = deleteBucket(set, "food"); // Food 15% + €180 -> Savings
    expect(out.find((b) => b.id === "food")).toBeUndefined();
    const sav = out.find((b) => b.id === "sav")!;
    expect(sav.percent).toBe(45);          // 30 + 15
    expect(sav.remaining).toBe(68000);     // 50000 + 18000
    expect(out.reduce((t, b) => t + b.percent, 0)).toBe(100);
  });
  it("throws when deleting the last bucket", () => {
    expect(() => deleteBucket([mk("only", "Only", 100)], "only")).toThrow();
  });
});
```
