# Bank Connection + Transaction Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user connect a bank via Plaid (sandbox), sync real transactions into their per-user Firestore store, **auto-split detected income into buckets server-side**, and keep data fresh with a **scheduled poll every 3 hours** — all behind a `BankProvider` interface so the provider can be swapped (GoCardless/TrueLayer) later without touching sync logic.

**Architecture:** Secrets and provider API calls live in **Firebase Cloud Functions** (server-side; the Plaid secret never reaches the browser). A `BankProvider` interface abstracts the provider; `PlaidAdapter` implements it. The client uses Plaid Link to get a `public_token`; a callable Function exchanges it for a long-lived `access_token`, stored in a **client-inaccessible** top-level Firestore collection (`bankConnections/{uid}` — denied by security rules, reachable only via the admin SDK). A shared **`syncOneUser(uid)`** core uses Plaid's cursor-based `transactionsSync`, maps results into our `Transaction` shape (integer cents, our sign convention), dedupes by provider transaction id, writes via the admin SDK, and — when it ingests income — runs the pure `splitIncome` and applies allocations (an admin-SDK twin of the existing `applyIncome` seam). Two triggers share that core: a **callable** (`syncTransactions`, for on-demand/just-connected) and a **scheduled** `onSchedule("every 3 hours")` poll over all connected users (the proactive engine — feeds are pull, not push).

**Tech Stack:** Firebase Cloud Functions (Node 20, `firebase-functions` v2 + `firebase-admin`), `plaid` Node SDK, `react-plaid-link` (client), Next.js 16 client, Vitest.

## Global Constraints

- **Blaze plan required** for Cloud Functions. Cost is $0 at this scale: GCP Always-Free allowances + the $300 trial credit cover it; a billing account (card) must be attached. Set a budget alert (~€5) as a safety net.
- **Secrets server-side only:** `PLAID_CLIENT_ID`, `PLAID_SECRET`, `PLAID_ENV=sandbox` live in Functions config/env — NEVER in the client bundle, NEVER in `NEXT_PUBLIC_*`. The Plaid `access_token` is a secret: stored only under `bankConnections/{uid}` (see security rule below), never returned to the client, never under `users/{uid}/**`.
- **Money is integer cents**, positive = money IN (our convention). **Plaid's `amount` is a floating major unit where POSITIVE = money OUT.** Mapping MUST: convert to cents via `toCents`, and **invert the sign** so a Plaid outflow becomes a negative `Transaction.amount` and a Plaid inflow (deposit/salary) becomes positive. Use `iso_currency_code`; MVP assumes EUR.
- **Per-user isolation + token secrecy:** all user-facing data stays under `users/{uid}/**`. `bankConnections/**` has NO client rule → denied to every client; only the admin SDK (Functions) accesses it.
- **Provider-agnostic:** sync/mapping/UI depend only on the `BankProvider` interface, never on `plaid` types directly outside `PlaidAdapter`.
- **Idempotent sync:** dedupe by provider `transaction_id`; store and reuse the Plaid cursor so re-runs don't duplicate or drop.
- **Reuse existing code:** `Transaction`/`Consent` types + path helpers from `@/lib/model/*`; `toCents` from `@/lib/model/money`; the pure `splitIncome` from `@/lib/split/engine` (for the follow-up). Do not redefine these.

`lib/bank/plaidAdapter.ts`:
```ts
import { toCents } from "@/lib/model/money";
import type { BankProvider, NormalizedTxn } from "@/lib/bank/provider";

export interface PlaidLikeTxn {
  transaction_id: string;
  amount: number;                 // Plaid: major units, POSITIVE = money OUT
  name: string;
  date: string;                   // YYYY-MM-DD
  iso_currency_code: string | null;
}

// Plaid sign convention is the inverse of ours. Invert here so the rest of the
// app uses one convention: positive = money in.
export function mapPlaidTxn(p: PlaidLikeTxn): NormalizedTxn {
  const amount = -toCents(p.amount); // invert sign; toCents rounds to integer cents
  return {
    providerTxnId: p.transaction_id,
    amount,
    description: p.name,
    bookedAt: p.date,
    isIncome: amount > 0,
  };
}

// Minimal shape of the Plaid client methods we use (keeps us decoupled from the SDK's types).
interface PlaidClientLike {
  linkTokenCreate(req: unknown): Promise<{ data: { link_token: string } }>;
  itemPublicTokenExchange(req: { public_token: string }): Promise<{ data: { access_token: string; item_id: string } }>;
  transactionsSync(req: { access_token: string; cursor?: string }): Promise<{
    data: { added: PlaidLikeTxn[]; next_cursor: string; has_more: boolean };
  }>;
}

export class PlaidAdapter implements BankProvider {
  constructor(private client: PlaidClientLike) {}

  async createLinkToken(uid: string): Promise<string> {
    const res = await this.client.linkTokenCreate({
      user: { client_user_id: uid },
      client_name: "MyBuckets",
      products: ["transactions"],
      country_codes: ["GB", "IE", "ES", "FR", "DE", "NL"],
      language: "en",
    });
    return res.data.link_token;
  }

  async exchangePublicToken(publicToken: string) {
    const res = await this.client.itemPublicTokenExchange({ public_token: publicToken });
    return { accessToken: res.data.access_token, itemId: res.data.item_id };
  }

  async syncTransactions(accessToken: string, cursor: string | null) {
    const res = await this.client.transactionsSync({
      access_token: accessToken,
      ...(cursor ? { cursor } : {}),
    });
    return {
      added: res.data.added.map(mapPlaidTxn),
      nextCursor: res.data.next_cursor,
      hasMore: res.data.has_more,
    };
  }
}
```

```ts
import { getFirestore, FieldValue } from "firebase-admin/firestore";
import type { NormalizedTxn } from "../../lib/bank/provider"; // shared type (or copy if path config forbids)

export async function saveConnection(uid: string, itemId: string, accessToken: string) {
  await getFirestore().doc(`bankConnections/${uid}/items/${itemId}`)
    .set({ accessToken, cursor: null, createdAt: new Date().toISOString() });
}
export async function listConnections(uid: string) {
  const snap = await getFirestore().collection(`bankConnections/${uid}/items`).get();
  return snap.docs.map((d) => ({ itemId: d.id, accessToken: d.get("accessToken") as string, cursor: d.get("cursor") as string | null }));
}
export async function saveCursor(uid: string, itemId: string, cursor: string) {
  await getFirestore().doc(`bankConnections/${uid}/items/${itemId}`).update({ cursor });
}
export async function writeTransactions(uid: string, txns: NormalizedTxn[]): Promise<number> {
  const db = getFirestore();
  const batch = db.batch();
  for (const t of txns) {
    const ref = db.doc(`users/${uid}/transactions/${t.providerTxnId}`); // id = providerTxnId → idempotent
    batch.set(ref, {
      amount: t.amount, description: t.description, bookedAt: t.bookedAt,
      bucketId: null, isIncome: t.isIncome,
    });
  }
  await batch.commit();
  return txns.length;
}
```
