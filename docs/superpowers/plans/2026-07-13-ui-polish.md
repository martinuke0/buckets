# UI Polish & Trust Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make MyBuckets look and feel like a trustworthy banking product — cohesive refined-dark design, an app shell with brand + centered layout, security signals on the scary bank-connect moment, a floating "liquid" bottom nav, and zero leaked internal strings.

**Architecture:** A shared `AppShell` (brand top bar + centered max-width column) wraps every authenticated screen; a redesigned floating `BottomTabBar` (glass pill, icon+label, active underline glow, raised gradient Sync center); a small set of shared primitives (`Card`, `TrustBadge`, `SectionLabel`) so screens stop hand-rolling inline styles. This is a visual/structural refactor — no business logic changes. Money math, sync, categorization, auth all stay exactly as-is.

**Tech Stack:** Next.js 16, React 19, Tailwind v4 + design tokens, Vitest + RTL.

## Global Constraints

- **Refined-dark, trust-first** (validated via mockups). Base `#0E0F13`, card `#171A21`, border `#23262F`, text `#E8EAED`, muted `#8A8F98`. **Gradient `#9945FF→#14F195` is a SIGNATURE, used sparingly** — hero number, primary buttons, active nav, the Sync button — NOT on every surface.
- **No emojis** anywhere in UI. Icons are inline SVG (stroke `currentColor`, `stroke-width` ~2).
- **No leaked internal strings**: users must never see provider ids, adapter names ("internal", "plaid", "mock"), debug values, or raw enum values. Scan and remove.
- **Security-first bank UX**: the connect-bank surface must state, in plain language: read-only access, we never see your login, bank-level encryption, revoke anytime, and borrow trust via "Powered by Plaid".
- **Money integer cents**; display only via `formatEuros`. This pass must not change any amount/calculation.
- **Accessibility kept**: nav items are real links with `aria-current`; buttons are `<button>`; sufficient contrast.
- **Reuse existing components** (`BucketCard`, `SafeToSpendHero`, `TransactionList`, `SimulateIncomeDialog`, `BucketSetup`) — restyle in place, don't rewrite their logic. Preserve all existing test-ids and props so current tests keep passing.
