# Buckets logo assets

Standalone SVG source files for the Buckets brand. The in-app components live at
`components/ui/primitives.tsx` (`Logo` + `Wordmark`), rendered inline for full
CSS-token control. These files here are the exportable/portable copies — use them
in marketing, README embeds, favicons, PDFs, etc.

## Files

- **`bucket-mark.svg`** — the bucket icon alone (outline bucket with Solana-gradient
  liquid fill inside). Solo mark; use as favicon, app-icon source, sticker, avatar.
- **`buckets-wordmark.svg`** — "Buckets" in the Solana gradient text; no icon. Use
  when the mark would be too small (dense text runs, footer credits).
- **`buckets-lockup.svg`** — the primary lockup: bucket-as-B + small "uckets" to
  the right. The bucket itself takes the place of the "B" so the mark reads as the
  first letter of the word. Use in AppShell top bar, sign-in H1, splash screens.

## Colors

Solana gradient: `#9945FF → #14F195`
Outline / text: `#E8EAED` (light) or `#0E0F13` (dark, on light backgrounds)
